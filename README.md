# Prompt Studio

نسخة مبسطة من التطبيق بدون أي Rules Engine أو Realism Engine أو Locks أو طبقات أولوية أو فحوصات تلقائية.

التطبيق يبني الـPrompt فقط من الاختيارات التي يحددها المستخدم ومن النص الذي يكتبه في خانة التفاصيل الإضافية.

## الحالة الحالية

- لا توجد قواعد هوية تلقائية.
- لا توجد تعليمات سيارة أو مقاعد أو نظام قيادة تلقائية.
- لا توجد قواعد إضاءة أو فيزياء تلقائية.
- لا توجد قواعد سياق تلقائية.
- لا توجد Output Guards أو Master Locks.
- لا توجد اختبارات قواعد قديمة.
