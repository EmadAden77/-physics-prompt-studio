# Physics Prompt Studio

تطبيق ويب ثابت وحتمي (deterministic) لتوليد برومبتات صور واقعية، مع محاكاة فيزيائية للكاميرا ومعالجة لاحقة محلية داخل المتصفح.

## المسار الكامل

1. **index.html** — استوديو المشاهد العامة مع فلترة ديناميكية للمكان والملابس وتسريحة الشعر والوضعية والزاوية والإضاءة والكاميرا والتأطير.
2. **car-selfie.html** — استوديو سيارات كامل (داخل/خارج) مع توليد Prompt، فحص الواقعية، ورفع ومعالجة الصور محليًا.

## توليد البرومبت

- يبني **23 قسمًا قانونيًا بالترتيب نفسه** في كل Prompt، بما فيها `[USER CONSTRAINTS]` التي تحمل نص المستخدم أو عبارة واضحة بعدم وجود قيود إضافية.
- يشمل هندسة الكاميرا، الإضاءة الفيزيائية، فيزياء العدسة، الواقعية البيولوجية، metadata متسقة مع الكاميرا المختارة، والتحقق النهائي.
- قفل الشعر مدمج داخل `[IDENTITY / SUBJECT]`: التسريحة تغيّر الاتجاه/الفرق/clumping فقط ولا تغيّر طول الشعر أو كثافته أو خطه.
- القيد الثقافي السعودي مدمج داخل `[SCENE]` عندما يكون المكان سعوديًا، ولا يُفرض على مشهد غير سعودي.
- نشاط الخلفية حتمي وواضح: quiet بلا أشخاص في الخلفية، normal يطلب 1-2 عند ملاءمة السياق، lively يطلب 3-5.
- المخرجات حتمية: نفس المدخلات تنتج نفس البرومبت.

## الكتالوجات

الكتالوج الأساسي يضم 43 مكانًا سعوديًا، 30 خيار ملابس، 120 طقمًا كاملًا، 30 تسريحة شعر، 15 وضعية سيلفي، 16 زاوية، و20 ملف إضاءة، إضافة إلى الكتالوجات الموسعة ومشاهد الالتقاط المتخصصة. الواجهة تبني خياراتها من هذه المصادر بدل تكرار البيانات الثابتة في HTML.

## التحقق

- `validateGeneratedPrompt()` يتحقق من وجود الأقسام الـ23، ترتيبها، عدم تكرارها، وعدم فراغها، ثم يفحص الكلمات الحرجة داخل الأقسام المناسبة.
- `validateRealism()` يرفض عبارات التجميل/الواقعية الزائفة عندما تكون توجيهًا إيجابيًا، ولا يعاقب العبارة نفسها إذا كانت منفية صراحة مثل `no studio lighting`.
- `core/scene-compatibility.js` يوفّر فحص نزاهة لمراجع profiles ويكشف القيم الميتة أو غير الموجودة.

## المعالجة اللاحقة

`core/photo-post-processing.js` يوفر ضوضاء مستشعر حتمية حسب ISO والـseed، vignetting، chromatic aberration، JPEG artifacts، HDR halo، white-balance drift وتقليل الحدة. المعالجة تتم محليًا ولا تستدعي API خارجيًا.

استوديو السيارات يوفّر Preset لـ Xiaomi 15 Ultra وiPhone 15 Pro Max، ISO تلقائي/يدوي، Seed، JPEG Quality، معاينة Original/Processed وتنزيل الصورة المعالجة. التبديل بين داخل/خارج يخفي الحقول غير المناسبة ويعيد الوضعية الخاصة بالوضع الجديد إلى default.

## البنية

- `core/prompt-generator.js` — المولد الرئيسي وفاحصا البنية والواقعية.
- `core/prompt-optimizer.js` — محسّن البرومبتات الموجودة.
- `core/scene-builder.js` — الكتالوجات الأساسية والأطقم والشعر.
- `core/expanded-catalogs.js` — كتالوجات موسعة.
- `core/scene-compatibility.js` — توافق المشهد وفحص نزاهة profiles.
- `core/scene-type-expansion.js` — مشاهد متخصصة وmetadata للفلترة.
- `core/automatic-scene-description.js` — وصف تلقائي للمشهد المتخصص.
- `core/saudi-location-lock.js` — قيد المواقع السعودية ومنع اختراع المعالم.
- `core/realistic-image-generator.js` — الواقعية السياقية ونشاط الخلفية.
- `core/photo-post-processing.js` — معالجة الصور الحتمية محليًا.

## الاختبارات

```bash
npm test
```

يشغّل الأمر `node --check` على كل ملفات JavaScript الأساسية، بما فيها `core/photo-post-processing.js`، ثم جميع `tests/*.test.mjs`. يوجد اختبار نزاهة شامل للكتالوجات، profiles، مشاهد التوسعة، حقول الواجهة، شجرة الملفات، أعداد الأسطر، ومصادر عدم الحتمية.

## مبادئ التنفيذ

- لا يستخدم كود الإنتاج `Math.random()` أو `Date.now()` أو `new Date()` أو `performance.now()` لتوليد النتائج.
- زر المشهد العشوائي يستخدم Seed صريحًا، ونفس Seed مع نفس الكتالوجات يعطي الاختيارات نفسها.
- لا توجد استدعاءات API خارجية مطلوبة لتوليد البرومبت أو معالجة الصورة داخل استوديو السيارات.
- التعريض وISO وHDR لا تُعامل كمصادر ضوء فيزيائية.
- مؤثرات العدسة والمعالجة تهدف لمحاكاة سلوك فوتوغرافي معقول، لا للتحايل على كواشف أو أنظمة تصنيف.
