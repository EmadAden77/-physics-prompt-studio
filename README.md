# Prompt Studio

تطبيق ويب ثابت لبناء برومبتات صور واقعية بطريقة موديولية وواضحة، مع فحص تعارضات لا يغيّر اختيارات المستخدم تلقائيًا.

## الوظائف الأساسية

- بناء Prompt من فكرة المشهد وخيارات واضحة.
- صورة مرجعية اختيارية مع أدوار منفصلة للهوية أو المظهر.
- هندسة كاميرا قابلة للتحكم: framing / focal length / distance / yaw / pitch / roll.
- فصل الإضاءة الفيزيائية عن Exposure / HDR / White Balance.
- موديولات واقعية مستقلة، وكل وحدة تعمل بوضع: إيقاف / تلقائي / صارم.
- إخراج مفصل، مختصر، JSON وNegative Prompt.
- Conflict Checker للتنبيه فقط، ولا يقوم بإصلاح أو تعديل الاختيارات تلقائيًا.
- Presets اختيارية تُطبّق حالة مشهد متماسكة بدون توريث إعدادات متعارضة من Preset سابق.
- بحث في المواقع والملابس، حفظ محلي، وإعادة ضبط لكل قسم أو للتطبيق كاملًا.
- مشهد اختياري داخل رنج روفر سبورت 2017 بيضاء، مع مقصورة L494 متوافقة مع الفترة، بدون فرض السيارة على بقية المشاهد.

## المواقع

جميع خيارات المواقع داخل السعودية ومصاغة كأماكن عامة وغير مميزة. لا يعتمد الكتالوج على أسماء مدن أو معالم أو مواقع سياحية أو مبانٍ مشهورة. عند كتابة موقع مخصص، ينبه Conflict Checker إذا اكتشف اسم مدينة معروفًا، دون تغيير النص تلقائيًا.

## البنية

- `index.html` — الواجهة وعناصر التحكم الثابتة.
- `styles.css` — التصميم المتجاوب.
- `app.js` — إدارة الحالة، التخزين المحلي، البحث، Presets والـLive Preview.
- `data/catalog.js` — الكتالوج الأساسي للمواقع والملابس والموديولات.
- `data/extensions.js` — خيارات المظهر والزوايا والوضعيات والإضاءات والمواقع الإضافية.
- `data/presets.js` — Presets جاهزة وقابلة للتعديل بعد التطبيق.
- `core/compiler.js` — تجميع المخرجات وفحص التعارضات.
- `tests/compiler-smoke.mjs` — اختبارات المترجم والـPresets والحالات المتعارضة.
- `tests/static-integrity.mjs` — فحص مسارات الاستدعاء وDOM وعلامات تعارض Git.
- `.github/workflows/ci.yml` — تشغيل الاختبارات تلقائيًا على `main` وPull Requests.

## الاختبار

لا توجد تبعيات تشغيل أو حزم خارجية مطلوبة للاختبارات.

```bash
npm test
```

يتحقق الأمر من سلامة صياغة JavaScript، المخرجات الأربع، Conflict Checker، Presets، المسارات، عناصر الواجهة، وعدم وجود علامات Git conflict غير محلولة.
