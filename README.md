# Physics Prompt Studio

تطبيق ويب ثابت وحتمي (deterministic) لتوليد برومبتات صور واقعية **مخصصة لـ ChatGPT Images فقط**، مع هندسة كاميرا، إضاءة فيزيائية، قيود سياقية، ومحاكاة معالجة لاحقة محلية داخل المتصفح.

## Target Lock — ChatGPT فقط

- الوجهة الوحيدة للمخرجات هي **ChatGPT / ChatGPT Images**.
- لا توجد خيارات Target لـ Codex أو OpenAI API أو أي منصة صور أخرى في الواجهة.
- `core/prompt-optimizer.js` يقفل `target_surface` داخليًا على `chatgpt` حتى لو حاول استدعاء برمجي تمرير target آخر.
- البرومبتات تستخدم تعليمات طبيعية مباشرة يمكن لصقها في ChatGPT، بدون معاملات خاصة بـ Midjourney أو Stable Diffusion مثل CFG / sampler / steps / model IDs.
- الهدف هو تحسين فهم ChatGPT للمشهد والهوية والهندسة والإضاءة والمواد، وليس إنتاج Prompt عام يحاول إرضاء عدة محركات في الوقت نفسه.

## Qwen Local Control (Experimental)

Qwen Local Control lives on the `qwen-local-control` branch only.
It is not merged into `main` and is not deployed to Vercel.
It requires local Ollama and is not a dependency of the core engine.

## المسار الكامل

1. **index.html** — استوديو المشاهد العامة لبناء Prompt جاهز لـ ChatGPT Images، مع فلترة ديناميكية للمكان والملابس وتسريحة الشعر والوضعية والزاوية والإضاءة والكاميرا والتأطير.
2. **car-selfie.html** — استوديو سيارات كامل (داخل/خارج) يستخدم نفس مولد الصور الأساسي الموجه إلى ChatGPT، مع فحص الواقعية ورفع ومعالجة الصور محليًا.

## توليد البرومبت

- يبني **23 قسمًا قانونيًا بالترتيب نفسه** في كل Prompt، بما فيها `[USER CONSTRAINTS]` التي تحمل نص المستخدم أو عبارة واضحة بعدم وجود قيود إضافية.
- يشمل هندسة الكاميرا، الإضاءة الفيزيائية، فيزياء العدسة، الواقعية البيولوجية، metadata متسقة مع الكاميرا المختارة، والتحقق النهائي.
- قفل الشعر مدمج داخل `[IDENTITY / SUBJECT]`: التسريحة تغيّر الاتجاه/الفرق/clumping فقط ولا تغيّر طول الشعر أو كثافته أو خطه.
- القيد الثقافي السعودي مدمج داخل `[SCENE]` عندما يكون المكان سعوديًا، ولا يُفرض على مشهد غير سعودي.
- نشاط الخلفية حتمي وواضح ويخضع لتوافق المكان والسياق؛ المشاهد الخاصة والهادئة تمنع النشاط غير المنطقي.
- المخرجات حتمية: نفس المدخلات تنتج نفس البرومبت، ونفس Seed يعيد نفس حالة المشهد العشوائي.

## الكتالوجات

الواجهة تبني خياراتها من كتالوجات المواقع والملابس والأطقم الكاملة وتسريحات الشعر والوضعيات والزوايا والإضاءة والكاميرات والتأطير، إضافة إلى الكتالوجات الموسعة ومشاهد الالتقاط المتخصصة. لا تُكرر البيانات الثابتة داخل HTML.

## التحقق

- `validateGeneratedPrompt()` يتحقق من وجود الأقسام الـ23، ترتيبها، عدم تكرارها، وعدم فراغها، ثم يفحص الكلمات الحرجة داخل الأقسام المناسبة.
- `validateRealism()` يرفض عبارات التجميل/الواقعية الزائفة عندما تكون توجيهًا إيجابيًا، ولا يعاقب العبارة نفسها إذا كانت منفية صراحة مثل `no studio lighting`.
- `core/scene-compatibility.js` يوفّر فحص نزاهة لمراجع profiles ويكشف القيم الميتة أو غير الموجودة.
- اختبارات Target Lock تمنع إعادة إدخال خيارات منصات أخرى إلى واجهة ChatGPT أو إلى `target_surface`.

## المعالجة اللاحقة

`core/photo-post-processing.js` يوفر ضوضاء مستشعر حتمية حسب ISO والـseed، vignetting، chromatic aberration، JPEG artifacts، HDR halo، white-balance drift وتقليل الحدة. المعالجة تتم محليًا ولا تستدعي API خارجيًا.

استوديو السيارات يوفّر Preset لـ Xiaomi 15 Ultra وiPhone 15 Pro Max، ISO تلقائي/يدوي، Seed، JPEG Quality، معاينة Original/Processed وتنزيل الصورة المعالجة. التبديل بين داخل/خارج يخفي الحقول غير المناسبة ويعيد الوضعية الخاصة بالوضع الجديد إلى default.

## البنية

- `core/prompt-generator.js` — المولد الرئيسي وفاحصا البنية والواقعية لبرومبتات الصور الموجهة إلى ChatGPT.
- `core/prompt-optimizer.js` — محسّن البرومبتات الموجودة مع Target ثابت على ChatGPT.
- `core/scene-builder.js` — الكتالوجات الأساسية والأطقم والشعر.
- `core/expanded-catalogs.js` — كتالوجات موسعة.
- `core/scene-compatibility.js` — توافق المشهد وفحص نزاهة profiles.
- `core/scene-type-expansion.js` — مشاهد متخصصة وmetadata للفلترة.
- `core/automatic-scene-description.js` — وصف تلقائي للمشهد المتخصص.
- `core/saudi-location-lock.js` — قيد المواقع السعودية ومنع اختراع المعالم.
- `core/realistic-image-generator.js` — الواقعية السياقية ونشاط الخلفية.
- `core/photo-post-processing.js` — معالجة الصور الحتمية محليًا.

## مبادئ التنفيذ

- لا يستخدم كود الإنتاج `Math.random()` أو `Date.now()` أو `new Date()` أو `performance.now()` لتوليد النتائج.
- زر المشهد العشوائي يولد Seed جديدًا عبر `crypto.getRandomValues()`، ونفس Seed مع نفس الكتالوجات يعطي الاختيارات نفسها.
- لا توجد استدعاءات API خارجية مطلوبة لتوليد البرومبت أو معالجة الصورة داخل استوديو السيارات.
- التعريض وISO وHDR لا تُعامل كمصادر ضوء فيزيائية.
- مؤثرات العدسة والمعالجة تهدف لمحاكاة سلوك فوتوغرافي معقول، لا للتحايل على كواشف أو أنظمة تصنيف.
- إضافة دعم لمنصة توليد أخرى مستقبلًا تتطلب قرارًا صريحًا وتغييرًا مقصودًا في Target Lock، وليست fallback تلقائيًا.
