# Physics Prompt Studio

تطبيق ويب ثابت وحتمي (deterministic) لتوليد برومبتات صور واقعية، مع محاكاة فيزيائية للكاميرا ومعالجة لاحقة محلية داخل المتصفح.

## المسار الكامل

1. **index.html** — استوديو المشاهد العامة (بورتريه، شوارع، مجالس، مقهى، وغيرها).
2. **car-selfie.html** — استوديو سيارات كامل (داخل/خارج) مع توليد Prompt، فحص الواقعية، ورفع ومعالجة الصور محليًا.

## ما يفعله التطبيق

### توليد البرومبت

- يبني 22 قسمًا إلزاميًا في كل برومبت أساسي.
- يشمل هندسة الكاميرا، الإضاءة الفيزيائية، فيزياء العدسة، الواقعية البيولوجية، وإشارات بيانات الالتقاط.
- يستخدم كتالوجات تضم 43 مكانًا سعوديًا، 30 خيار ملابس، 16 زاوية سيلفي، 15 وضعية، و20 ملف إضاءة.
- يعمل محليًا دون استدعاء API خارجي أثناء توليد البرومبت.
- المخرجات حتمية: نفس المدخلات تنتج نفس البرومبت.

### التحقق (Validation)

- `validateGeneratedPrompt()` — يتحقق من البنية ووجود الأقسام والقواعد الأساسية المطلوبة.
- `validateRealism()` — يتحقق من الواقعية، ويرفض المصطلحات غير المناسبة مثل `studio lighting` عند استخدامها كتوجيه إيجابي بلا منطق فيزيائي، ويتجاهلها عندما تظهر داخل قسم `[NEGATIVE CONSTRAINTS]` بوصفها محظورات.
- فحص الواقعية منفصل عن فحص البنية حتى تبقى مسؤولية كل طبقة واضحة.

### المعالجة اللاحقة (Post-Processing)

- `core/photo-post-processing.js` يوفر:
  - ضوضاء مستشعر تعتمد على ISO وبذرة ثابتة (seed).
  - تظليل عدسة (vignetting).
  - انحراف لوني (chromatic aberration).
  - عيوب JPEG مبسطة وحتمية.
  - HDR halo محدود.
  - انحراف توازن أبيض وتقليل حدة ضمن خط المعالجة.
- يتوفر preset أساسي لـ **Xiaomi 15 Ultra Front** من وحدة المعالجة.
- يوفر استوديو السيارات preset إضافيًا لـ **iPhone 15 Pro Max Front** داخل طبقة الواجهة دون تغيير نواة المعالجة.
- Deterministic: نفس الصورة + نفس الإعدادات + نفس `seed` تعطي نفس نتيجة المعالجة الحسابية.
- لا adversarial noise، لا detector targeting، ولا frequency-domain perturbations.
- المعالجة تتم محليًا في المتصفح ولا ترفع الصورة إلى خدمة خارجية.

## البنية

- `core/prompt-generator.js` — المولد الرئيسي وفاحصا البنية والواقعية.
- `core/prompt-optimizer.js` — محسّن البرومبتات الموجودة.
- `core/scene-builder.js` — كتالوجات المشاهد والملابس والوضعيات والزوايا والإضاءة.
- `core/expanded-catalogs.js` — كتالوجات موسّعة.
- `core/scene-compatibility.js` — توافق خيارات المشهد.
- `core/scene-type-expansion.js` — توسيع أنواع المشاهد.
- `core/saudi-location-lock.js` — قيد المواقع السعودية ومنع اختراع المعالم عند الحاجة.
- `core/realistic-image-generator.js` — حزمة الواقعية وقواعدها.
- `core/photo-post-processing.js` — معالجة الصور الحتمية محليًا.
- `car-selfie.js` — ربط استوديو السيارات بالمولد، فحص الواقعية، ومعالجة الصور.

## الاختبارات

```bash
npm test
```

يشغّل الأمر فحص syntax لملفات JavaScript الأساسية ثم جميع ملفات `tests/*.test.mjs` باستخدام Node.js Test Runner. يتضمن الاختبار الشامل تحققًا من حتمية توليد البرومبت، عدد الأقسام الإلزامية، أحجام الكتالوجات الأساسية، سلامة فحص الواقعية، حتمية ضوضاء المستشعر، وربط استوديو السيارات بوحدات التوليد والمعالجة.

## مبادئ التنفيذ

- لا يستخدم المسار الحتمي `Math.random()` لتوليد النتائج.
- لا توجد استدعاءات API خارجية مطلوبة لتوليد البرومبت أو معالجة الصورة داخل استوديو السيارات.
- التعريض وISO وHDR لا تُعامل كمصادر ضوء فيزيائية.
- مؤثرات العدسة والمعالجة تهدف لمحاكاة سلوك فوتوغرافي معقول، لا للتحايل على كواشف أو أنظمة تصنيف.
