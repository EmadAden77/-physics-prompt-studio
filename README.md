# Prompt Studio

تطبيق ويب ثابت لبناء برومبتات صور واقعية بطريقة موديولية وواضحة.

## الفكرة

- يبدأ المستخدم من فكرة المشهد.
- يختار دور الصورة المرجعية إن وُجدت.
- يحدد نوع الالتقاط وهندسة الكاميرا يدويًا.
- الإضاءة الفيزيائية منفصلة عن Exposure / HDR / White Balance.
- موديولات الواقعية مستقلة ويمكن ضبط كل واحدة على: إيقاف / تلقائي / صارم.
- الناتج متوفر بصيغة مفصلة، مختصرة، JSON وNegative Prompt.
- يوجد Conflict Checker للتنبيه فقط، ولا يغيّر اختيارات المستخدم تلقائيًا.

## المواقع

جميع خيارات المواقع داخل السعودية ومصاغة كأماكن عامة وغير مميزة، بدون أسماء مدن أو معالم أو مواقع سياحية أو مبانٍ مشهورة.

## البنية

- `index.html` — الواجهة.
- `styles.css` — التصميم المتجاوب.
- `app.js` — إدارة الحالة والـLive Preview.
- `data/catalog.js` — كتالوج الخيارات والمواقع السعودية العامة.
- `core/compiler.js` — تجميع الـPrompt وفحص التعارضات.
