# Physics Prompt Studio V4

مولد برومبتات سيلفي واقعية موجّه لـ ChatGPT Images وGoogle Gemini. يركز على قفل الهوية من الصورة المرجعية، فيزياء السيلفي، مقصورة Range Rover Sport L494 بنظام قيادة يسار، والواقعية السياقية في السعودية.

## Master Realism Engine

يعتمد التطبيق مسار تنفيذ مختصرًا من تحليل الطلب حتى الفحص الجنائي النهائي، ويحل التعارضات عبر أربع طبقات أولوية. القواعد العامة مستقلة عن موديولات المشهد، ولا تُفعّل إلا الوحدات المطابقة للاختيارات الحالية مثل السيلفي، داخل/خارج السيارة، الإضاءة المنخفضة، ضوء النهار، وإضاءة النافذة.

يختار المستخدم وقت المشهد فقط (صباح، ظهر، عصر، نهار عام، أو ليل)، ثم يحسب التطبيق تلقائيًا منطق الإضاءة الفيزيائية وزاوية السيلفي المناسبة وفق المكان، نوع المشهد، المقعد والوضعية.

## قفل مقعد السائق السعودي

يعتمد التطبيق مقصورة قيادة يسار (LHD) كما هو شائع في السعودية، ويثبت مقعد السائق بالترابط الفيزيائي بدل اتجاه الصورة: السائق في المقعد الأمامي الأيسر على محور المقود والعدادات والدواسات، وباب السائق عند كتفه الأيسر، والكونسول عند فخذه الأيمن، ثم مقعد الراكب بعد الكونسول. لا يُستخدم يمين/يسار شاشة السيلفي لإثبات المقعد لأن معاينة الكاميرا الأمامية قد تكون معكوسة.

تتضمن المواقع السعودية سياقات سكنية وتجارية وخدمية وساحلية وصحراوية متعددة. ويحسب محرك كثافة الحياة تلقائيًا الأشخاص والمركبات والحركة والسلوك اليومي وفق المكان والوقت بدل استخدام ازدحام ثابت أو خلفية مصطنعة.

تحتوي الواجهة على خزانة ملابس موسعة بخامات وتنسيقات كاملة، وخيارات نظارات طبية وشمسية على العين أو فوق الرأس أو معلّقة بالملابس، مع قواعد تماس وانعكاس ومنع التكرار داخل الـPrompt الناتج.

إصدار V2: 20 تنسيق ملابس إضافيًا و10 خيارات نظارات ومواضع واقعية.

إصدار V3: محرك واقع سعودي فيزيائي إلزامي يربط المكان والوقت تلقائيًا بنوع الأسفلت والرصيف والمداخل والتصريف وحالة الصيانة والغبار والحركة البشرية والمرورية. يسمح بفوضى يومية محدودة لها سبب، ويمنع الشوارع المعقمة والفوضى الزخرفية والمبالغة في الإهمال.

إصدار V4: Master Rules Engine فعلي بقواعد شرطية ذات أولوية، كشف وتصحيح تعارضات، سجل ثقة، قفل «المرئي فقط»، وفصل MUST عن AVOID. القواعد موزعة داخل `rules/` ويمكن اختبارها عبر `node tests/master-rules.test.js`.

تصحيح V4.1: تقارير القواعد والثقة أصبحت داخلية ولا تُنسخ إلى برومبت ChatGPT. المخرج النهائي صار برومبتًا واحدًا مختصرًا مع قفل وقت صريح يمنع خلط الليل بالنهار، وقفل أقوى للتعبير والكادر وحجم المقود والنصوص التجارية.

يبدأ الـPrompt الآن بقفل مرئي عالي الأولوية يمنع اتساع الكادر غير المطلوب، ظهور ذراع السيلفي، تضخم المقود، استبدال التعبير بابتسامة، تضخيم الشعر، الشعارات المقروءة، والإضاءة الأمامية غير المفسرة. كما اختُصر قفل L494 ليصف الأجزاء المرئية فقط.

تصحيح V2 البصري: القيود المرئية الحاسمة تسبق التفاصيل الوصفية داخل المخرجات.
