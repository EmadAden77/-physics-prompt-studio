# Architecture V7 — Dual-Mode Car Selfie Physics Studio

## النطاق

يبقى التطبيق مقسومًا إلى General Studio مستقل وصفحة سيارات مستقلة `car-selfie.html`. داخل صفحة السيارات نفسها يوجد الآن قفل وضعين متنافيين:

1. `inside`: تصوير سيلفي داخل السيارة.
2. `outside`: تصوير ذاتي بالخارج بجانب سيارة متوقفة.

الوضع غير النشط لا يختبئ بصريًا فقط؛ حقوله لا تدخل أصلًا في الحالة normalized state ولا في compiler النهائي.

## البيانات

- `data/carSelfieCommonCatalog.js`: Xiaomi 15 Ultra، المركبات، الأماكن السعودية، الطقس، الإضاءة الخارجية، الملابس، الأقمشة، الشعر، الوجه والمعالجة المشتركة.
- `data/carSelfieInsideCatalog.js`: المقعد، الحركة، الالتقاط الأمامي داخل المقصورة، اليدان، LHD، الخامات، العدادات، السقف، النوافذ، الفوضى والمصادر الداخلية.
- `data/carSelfieOutsideCatalog.js`: وضعيات الوقوف، حالة الطلاء، الالتقاط الأمامي أو rear-camera remote/self-timer، وقواعد الخارج.

تم حذف `data/carSelfieCatalog.js` المختلط.

## Xiaomi 15 Ultra

- السيلفي اليدوي يستخدم الأمامية فقط: نحو 21mm equivalent، 32MP، f/2.0، Fixed Focus، EIS/HDR.
- العدسات الخلفية الممثلة في وضع الخارج فقط عند تثبيت الهاتف/المؤقت: 23mm f/1.63 و70mm f/1.8.
- لا توجد عدسة 75mm؛ طلب 75mm يُطبّع حتميًا إلى 70mm الرسمية.
- Leica Authentic/Vibrant لا يظهران مع الكاميرا الأمامية.

## فصل الوضعين

`normalizeCarState` يختار whitelist مختلفة لكل وضع:

- inside-only: `seat`, `handPose`, `cabinMaterial`, `clusterType`, `roofType`, `windowState`, `clutterLevel`, `cabinEmitter`.
- outside-only: `standingPose`, `paintCondition`.

أي حقل من الوضع الآخر يُسقط من الحالة ولا يستطيع الوصول للمترجم أو JSON.

## الواجهة

الصفحة أصبحت Wizard من 6 خطوات:

1. الوضع.
2. الطلب الأولي والفلترة الحية.
3. السيارة.
4. الشخص والكاميرا والأقمشة والشعر والوجه.
5. الإضاءة والبيئة.
6. المخرجات والفحص.

لا تستخدم القوائم `<option disabled>` أو `<option hidden>`. بدل ذلك يعاد بناء القائمة لتحتوي الخيارات المتوافقة فقط. تبويبا الوضع يخفيان كتل الوضع الآخر بالكامل.

تمت إضافة SVG محلي يوضح مكان الكاميرا واتجاهها التقريبي مع Yaw/Pitch/Roll بدون صور خارجية.

## فيزياء الداخل

- LHD ثابت.
- كاميرا أمامية فقط في سيلفي الداخل.
- Arm reach = 30–50cm للسيلفي اليدوي.
- الهاتف اليدوي ممنوع أثناء الحركة؛ السائق المتحرك يستخدم dashboard mount مع gaze للطريق.
- فوضى المقصورة تخضع للجاذبية، الدعم، تماس السطح، ظل التلامس والتسارع.
- إضاءة العدادات/الهاتف/السقف محلية ولا تستطيع إضاءة المقصورة كاملة بلا وصول ضوئي فعلي.

## فيزياء الخارج

- السيارة متوقفة دائمًا أثناء وقوف الشخص بجانبها.
- السيلفي اليدوي الخارجي يستخدم الأمامية 21mm فقط.
- 23mm/70mm الخلفية لا تُتاح إلا في `remote-rear`: هاتف مثبت + مؤقت/ريموت، لذلك لا تُقدَّم كذراع سيلفي مستحيلة.
- وضعيات: بجانب باب السائق، اتكاء خفيف، فتح الباب الخلفي، النظر للكاميرا، النظر للسيارة.
- الطلاء يعكس البيئة حسب انحناء اللوح واتجاه السطح؛ الزجاج يستخدم transmission + Fresnel؛ الإطارات لها contact patch وظل تماس.

## الفيزياء المشتركة

- Saudi Place Physics: أسفلت/رصيف/سدر/غاف/نخيل/طقس/خصوصية المارة دون مدن أو معالم.
- Fabric Physics: نوع قماش مستقل + sheen مستقل + wrinkle profile مستقل، مع فلترة توافقية حسب قطعة الملابس.
- Hair Physics: density/hairline lock ثابت + حركة مرتبطة بالوضع والهواء + anisotropic specular واقعي.
- Facial Physics: تعابير مبنية على العضلات، اتجاه نظر مستقل، مسام وخطوط دقيقة بدون uncanny smoothing.
- Physical Light Causality: HDR/Exposure/WB لا يخلقون ضوءًا، والظل الثاني يحتاج مصدرًا ثانيًا حقيقيًا.

## Conflict Checker

- `strict`: fatal/error يمنع الإخراج.
- `auto`: يعرض نفس التعارضات ولا يمنع النص.
- الفلترة في الواجهة تمنع معظم التركيبات غير الصالحة قبل وصولها للفحص، بينما يظل validator دفاعًا ثانيًا.

## الحتمية

لا `Math.random()` ولا `Date.now()` في Data/Core. التحليل النصي Rule-based؛ نفس الطلب + نفس الوضع + نفس الحقول = نفس الحالة ونفس البرومبت.

## الاختبار

`npm test` يشغّل syntax checks، اختبارات الوحدة، اختبارات الفصل داخل/خارج، Xiaomi optics، 75→70، الفلترة، فيزياء الضوء/القماش/الشعر/الوجه، الوقوف الخارجي، الفوضى الداخلية، Strict/Auto، JSON determinism وStatic Integrity.
